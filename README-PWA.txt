# Jogo da Velha Pro Max — PWA

Arquivos:
- `index.html` — jogo
- `manifest.json` — configuração de instalação da PWA
- `sw.js` — Service Worker/cache
- `icons/` — ícones da aplicação

## GitHub Pages
Coloque todos estes arquivos na mesma pasta do repositório, mantendo a pasta `icons`.
Depois abra o endereço do GitHub Pages em HTTPS.

No Android/Chrome, use **Adicionar à tela inicial** / **Instalar app**.

Observação: os modos que dependem de Internet, como o multiplayer P2P e as bibliotecas carregadas por CDN, continuam dependendo de conexão quando ainda não estiverem em cache.
